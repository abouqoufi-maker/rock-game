🪨📄✂️ Rock Game

A simple Rock Paper Scissors game built with Python.

The player chooses between Rock (7ajar), Paper (waraq), and Scissors (miqas), while the computer randomly selects an option.

The player can also choose the number of rounds to play. If there is a draw, an additional round is added to the game.

🚀 Features
🎮 Play Rock Paper Scissors against the computer
🤖 Computer makes random choices
🔢 Choose the number of rounds
➕ Draws give the player an additional round
🪨 Rock (7ajar)
📄 Paper (waraq)
✂️ Scissors (miqas)
💻 Runs directly in the terminal
🛠️ Technologies
Python 3
random module
random.choice()
while loops
if / elif / else
User input
Variables and counters
▶️ How to Run

Make sure Python 3 is installed on your computer.

Clone the repository:

git clone https://github.com/YOUR-USERNAME/rock-game.git

Go to the project folder:

cd rock-game

Run the program:

python rock_game.py
🎮 How to Play
Enter the number of choices you want to play.
Choose one of the following:
7ajar
waraq
miqas
The computer randomly chooses an option.
The program displays both choices.
The result is displayed.
If the result is a draw, you receive an additional choice.
